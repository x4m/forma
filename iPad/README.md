# Forma на iPad — без кабеля

Этот каталог сохраняет экспериментальный прототип с 14 исходными стилями. В Mac-версии в корне репозитория доступны 18 стилей. Прототип собран в Xcode, но успешный запуск на физическом iPad пока не подтверждён.

Для создания архива запусти `./iPad/package.sh` из корня репозитория. Результат: `build/Forma-iPad-Playgrounds.zip`.

Подготовлен проект **Forma.swiftpm** для запуска в **Swift Playgrounds**. В архиве `Forma-iPad-Playgrounds.zip` лежат исходники и встроенный пингвин. Это проект приложения, который собирается на iPad, а не готовый установочный IPA.

## Передача и запуск

1. Установи бесплатное приложение Apple [Swift Playgrounds](https://apps.apple.com/app/swift-playgrounds/id908519492) на iPad. iPadOS 26.5 подходит; текущая версия Playgrounds требует iPadOS 18 или новее.
2. На Mac найди `Forma-iPad-Playgrounds.zip`, нажми **Поделиться → AirDrop** и выбери iPad.
3. На iPad прими файл и сохрани в «Файлы», если появится выбор приложения.
4. В «Файлах» нажми на ZIP, чтобы распаковать. Появится проект **Forma.swiftpm**.
5. Открой Swift Playgrounds. На стартовом экране выбери **Обзор / Browse**, найди `Forma.swiftpm` и открой его. Также можно попробовать открыть проект прямо из «Файлов».
6. Нажми **▶ Run**. Первый запуск включает компиляцию и может занять некоторое время. Включи полноэкранный предпросмотр, чтобы пользоваться интерфейсом без редактора кода.

Кабель и платная подписка Apple Developer Program для такого запуска своего проекта не нужны. Это запуск через Swift Playgrounds; отдельная установка приложения на домашний экран здесь не выполняется.

## Использование

- **Фото** — выбор из медиатеки через системный PhotosPicker.
- Кнопка с **папкой** — открытие изображения из «Файлов».
- Нижняя лента — все 14 стилей с номерами исходного референса.
- **Форма / Фото** — сравнение результата с исходником.
- **Настройки** — кнопка с ползунками в узком окне; в широком окне настройки видны слева.
- **Экспорт** — сохранение SVG или PNG 1536 × 1536 через системный диалог «Файлы».
- **Белый фон** — выключи для прозрачного экспорта.

Все преобразования выполняются на iPad. Лучше использовать один объект на однотонном или прозрачном фоне. Это те же алгоритмические интерпретации, что в Mac-версии; сложный фон и художественные формы из референса не распознаются нейросетью.

## Что меняется при переносе с Mac

`Engine.swift` сохраняет алгоритмы выделения объекта и генерации 14 стилей. `Geometry.swift` использует Core Graphics для векторных путей и `UIImage.pngData()` вместо `NSBitmapImageRep`.

`TabletView.swift` — адаптивный SwiftUI-интерфейс для касаний, `PhotosPicker`, `fileImporter` и `fileExporter`. `TabletModel.swift` хранит состояние и выполняет обработку вне главного потока. `FormaApp.swift` создаёт окно. `Package.swift` объявляет приложение для Swift Playgrounds через `AppleProductTypes.iOSApplication`.

В проекте нет сторонних пакетов или зависимостей, которые нужно загружать из интернета.

## Проверка и границы проверки

Сам проект Swift Playgrounds успешно собран Xcode для физического устройства iOS/iPadOS без подписи, включая манифест, все исходники, иконку и встроенную картинку. Базовые алгоритмы унаследованы от проверенной Mac-версии. На физическом iPad и внутри Swift Playgrounds эта версия пока не запускалась; импорт проекта, выбор фото и сохранение результата нужно подтвердить первым запуском на твоём iPad.
